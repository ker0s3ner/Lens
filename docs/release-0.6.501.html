0.6.501 — Fourier

See API arguments at statically flagged behavior call sites.

  • Capture register values for each debugger stop and keep that snapshot with its event.
  • Decode x86-64 System V, Windows x64, and AArch64 argument registers.
  • Use known API prototypes for parameter names and C types; use argN where they are unavailable.
  • Show captured values beneath behavior-callsite events.
  • Include argument names, types, register names, and raw values in TSV and JSON event handoffs and dynamic-trace JSON.
  • Leave pointers as raw values; Lens does not read memory through them here.

These are values observed at a breakpoint before the API executes. They do not prove the call completed. Other calling conventions are not decoded yet. The weighted IDA Pro parity estimate remains 41.8%.
