Lens release

0.6.487 — Fourier

Callback-aware type recovery and more focused defensive triage.

  • Prototype-seeded pointer parameters now flow into decompiler call arguments and inferred locals.
  • Local function-pointer calls recover signatures through callback typedef aliases.
  • Callback return types flow into local declarations and pointer dereferences.
  • Null callback arguments render with C-compatible function-pointer casts.
  • Persistence triage now targets service, task, and login-item installation APIs rather than general settings access.
  • Credential-store imports produce a separate, explainable analyst-triage clue.
  • Observed runtime calls continue matching behavior signals when evidence includes explanatory notes.
  • Includes the pointer-recovery and runtime-call work accumulated since 0.6.486.
  • IDA Pro parity estimate remains 39.5% weighted capability coverage; the 50% target remains unmet.
  • GitHub Actions builds the release artifact; no local build or installation was performed.
