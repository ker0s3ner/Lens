0.6.514 — Fourier

More complete forwarding-thunk analysis, typed Linux/BSD APIs, and sandbox behavior review.

  • Resolve x86/x64 forwarding stubs that load known function addresses into registers before a tail jump.
  • Resolve RIP-relative lea address materialization followed by a register jump.
  • Resolve import-slot loads followed by a register jump.
  • Recognize known-target x86 push immediate; ret forwarding stubs.
  • Add resolved targets from these forms to function call lists and call xrefs.
  • Match cross-capability heuristic evidence to each participating imported API.
  • Show correlated heuristic signals on matching runtime API call events.
  • Expose those call events to existing category filters and behavior call-site watchpoints.
  • Add a typed openat prototype for directory-relative file access.
  • Add a typed openat2 prototype while preserving its options structure as opaque.
  • Add typed renameat and renameat2 prototypes with rename flags.
  • Add typed unlinkat support for directory-relative removal.
  • Add typed faccessat and fchownat directory-relative interfaces.
  • Add typed execveat descriptor-based execution support.
  • Add typed Linux close_range and getrandom interfaces.
  • Add typed prctl and seccomp policy operations.
  • Add typed pidfd_open and pidfd_send_signal process interfaces.
  • Add typed copy_file_range and splice transfer interfaces.
  • Add typed Landlock ruleset creation, rule addition, and self-restriction interfaces.
  • Add typed OpenBSD pledge and unveil sandbox interfaces.
  • Identify sandbox and syscall-policy imports as a separate static capability.
  • Show an evidence-linked, low-severity sandbox policy signal without implying malicious intent.
  • Add a dedicated sandbox category to runtime-event filters.
  • Classify path-relative file changes and zero-copy transfers as filesystem call events.
  • Classify pidfd operations and descriptor-range changes as process call events.
  • Render common Linux openat access, create, directory, sync, and temporary-file flags.
  • Render renameat2, unlinkat, faccessat, fchownat, and execveat flags symbolically.
  • Render close_range and getrandom flags symbolically.
  • Render known prctl options and seccomp operations/filter flags symbolically.
  • Keep the weighted IDA Pro estimate at 41.8% until the next full category audit; the 50% target remains unmet.
