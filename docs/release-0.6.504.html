Lens release

0.6.504 — Fourier

More dependable pseudocode for indexed struct and array accesses.

  • Normalize nested pointer additions and subtractions regardless of operand order, while checking offset arithmetic for overflow.
  • Reconstruct `base[index].field` and nested struct-array paths from scaled multiplication or power-of-two shifts.
  • Reconstruct indexed scalar arrays and array members nested within structs, including constant index biases and signed indices.
  • Use known pointer parameter types to cast otherwise untyped call arguments, while preserving string literals.
  • Keep ambiguous unions, unsupported layouts, and out-of-range offsets as explicit dereferences.

The weighted IDA Pro parity estimate remains 41.8%; the 50% target remains unmet. GitHub Actions builds the release artifact.
