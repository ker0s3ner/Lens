0.6.516 — Fourier

November 2026 · GitHub release

  • Reuse call-graph node rectangles for hit testing, edge clipping, and drawing instead of recomputing geometry for each edge each frame.
  • Remove dead generated temporaries with successor-aware CFG liveness in functions up to 512 blocks; preserve calls, reads, and other observable evaluations.
  • Use PE target pointer width for CodeView/PDB arrays, recognize Windows wide-character and HRESULT sizes, and reject members outside their declared record.
  • Read ARM32, Thumb, and ARM64 PE .pdata as 8-byte packed-unwind records and enable those function hints; keep validated 12-byte x64 records.
  • Filter statically matched cryptography, credential-store, persistence, and process-injection calls as separate runtime categories.
  • API-family labels remain heuristic triage, not proof that an operation completed or evidence of malicious intent.
  • Last full weighted IDA Pro audit: 41.8% at 0.6.514; 0.6.515 and 0.6.516 await a fresh audit. The 50% goal remains in progress.
