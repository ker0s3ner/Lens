0.6.499 — Fourier

More accurate C record layouts from scoped packing directives.

  • Honor alignment caps set by #pragma pack(n) before a record.
  • Restore natural alignment with #pragma pack() or #pragma pack(0).
  • Support nested unnamed and named push/pop frames, including explicit caps on push and pop.
  • Capture the active cap when the record declaration begins.
  • Accept caps of 1, 2, 4, 8, or 16 bytes; report malformed values and unmatched pops clearly.
  • Reject packing changes inside a record body because field-by-field packing is not yet modeled.
  • Keep packed attributes and #pragma pack(1) on the same byte-aligned layout path.

The weighted IDA Pro parity estimate remains 41.8%. Packing directives guide layout recovery and do not infer unsupported compiler-specific bitfield ABI rules.
