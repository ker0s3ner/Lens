Lens release

0.6.512 — Fourier

Simple jump-table cases now appear as structured switch bodies in pseudocode.

  • Resolve jump-table targets to blocks in the current function.
  • Keep signed and nonsequential case indices.
  • Use enum member names for typed switch selectors.
  • Group multiple case labels that share the same block.
  • Inline supported single-block cases into the switch statement.
  • Render shared continuations as break and preserve direct return cases.
  • Avoid emitting inlined case blocks a second time later in the function.
  • Require one shared continuation and safe case layout before structuring the switch.
  • Keep labels and gotos when cases have external entries or complex control flow.
  • Weighted IDA Pro parity remains 41.8%; the 50% target remains unmet.

GitHub Actions builds the release artifact; no local build or installation was performed.
