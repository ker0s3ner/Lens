Lens release

0.6.485 — Fourier

Debugger replay, native local sessions, improved analysis, and large-file measurements.

  • Added bounded offline instruction-trace replay with navigation through recorded PCs.
  • Added a consent-gated native local-child debugger session lifecycle.
  • Recovered more DWARF member offsets using DW_OP_plus_uconst.
  • Corrected M68k EXT.W and EXT.L sign-extension semantics.
  • Made decompiler copy propagation more conservative across adjacent assignments.
  • Improved dense call-graph layout by indexing visible neighbors and preserving crossing edges.
  • Added a repeatable GitHub large-file gate; a 134,225,920-byte synthetic ELF completed in 5.427 seconds at 393.36 MiB peak RSS.
  • GitHub Actions builds the release artifact; no local device build or installation was performed.
