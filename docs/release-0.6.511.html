0.6.511 — Fourier

Safe decompiler values now flow through longer CFG branch and merge chains.

  • Repeat CFG copy and constant propagation until a full pass makes no change.
  • Carry resolved values through several branch and merge blocks.
  • Revisit downstream merges when upstream propagation exposes new inputs.
  • Run propagation before register liveness and final pseudocode emission.
  • Keep copy propagation stopped at source or destination reassignment.
  • Keep constant propagation stopped at destination reassignment.
  • Skip backward-address merge edges in these iterative passes.
  • Keep calls, loads, ternaries, and opaque expressions out of convergent copies.
  • Limit eligible merged expressions to 256 nodes.
  • Update block definitions and branch, return, and indirect terminators consistently.
  • Weighted IDA Pro parity remains 41.8%; the 50% target remains unmet.

GitHub Actions builds the release artifact; no local build or installation was performed.
