Lens release

0.6.506 — Fourier

Consistent reads and edits across virtual zero-filled memory.

  • Owned reads combine file-backed data and virtual zeros into one result, stopping at the mapped segment boundary.
  • Pointer reads can cross from initialized bytes into zero-fill without dropping the remaining pointer bytes.
  • Rhai scalar and byte accessors now read virtual zero-fill through the same image API.
  • Applied enum values and struct fields can be inspected in zero-filled memory.
  • Large field reads stay bounded; character-array previews stop at 1 MiB and mark unterminated truncation.
  • In-memory patches can edit zero-filled addresses by materializing the edited prefix only.
  • ELF relocations can write into BSS through the shared image writer.
  • Zero-fill materialization retains the former 64 MiB cap, and patch address arithmetic is checked for overflow.
  • Virtual-only bytes remain unsavable to the original file, which requires file-backed storage.
  • Weighted IDA Pro parity remains 41.8%; the 50% target remains unmet.

GitHub Actions builds the release artifact; no local build or installation was performed.
