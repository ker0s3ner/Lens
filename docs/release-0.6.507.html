Lens release

0.6.507 — Fourier

More reliable local type declarations across branch assignments.

  • Infer a local declaration when its assignments across basic blocks agree on one type.
  • Preserve pointer, struct-pointer, and function-pointer types across repeated assignments when the type evidence agrees.
  • Keep prototype-seeded parameter types authoritative when the parameter is reassigned.
  • Merge a constant-zero assignment as a null pointer only when another assignment establishes one consistent pointer type.
  • Recognize folded integer constant expressions with value zero as null-pointer alternatives.
  • Leave zero-only variables untyped because zero alone does not identify a pointer.
  • Leave nonzero unknown values and conflicting assignment types unresolved.
  • Keep user-assigned local types above inferred assignment types.
  • Weighted IDA Pro parity remains 41.8%; the 50% target remains unmet.

GitHub Actions builds the release artifact; no local build or installation was performed.
