0.6.516 — Fourier

CFG-aware decompiler cleanup, wider PE type and function-boundary recovery, and clearer runtime behavior triage.

  • Reuse call-graph node rectangles for hit testing, edge clipping, and drawing instead of recomputing geometry for each edge each frame.
  • Remove dead generated temporaries with successor-aware CFG liveness in functions up to 512 blocks.
  • Keep calls, memory reads, and other observable evaluations when their result is unused; larger functions retain the bounded conservative cleanup.
  • Size CodeView/PDB pointer arrays using the target PE pointer width, including 32-bit targets.
  • Recognize Windows wide-character and HRESULT element sizes when recovering fixed arrays.
  • Reject PDB struct and union layouts when a recovered member extends beyond its declared record.
  • Parse ARM32, Thumb, and ARM64 PE .pdata as 8-byte packed-unwind entries and enable those function-boundary hints during loading.
  • Keep x64 PE .pdata on 12-byte begin/end/unwind records with function-range validation.
  • Label statically matched cryptography and credential-store API calls separately in runtime-event filters and exports.
  • Label statically matched service, scheduled-task, and login-item calls as persistence activity.
  • Distinguish remote-memory and remote-thread calls as process-injection primitives when static signals match.
  • These API-family labels are heuristic triage; they do not prove an operation completed or establish malicious intent.
  • Carry forward the last full weighted audit, 41.8% at 0.6.514. Builds 0.6.515 and 0.6.516 have not had a fresh category audit; the 50% goal remains in progress.

GitHub Actions builds the release artifact; no local build or installation was performed.
