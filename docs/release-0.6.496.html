0.6.496 — Fourier

Type-aware pointer indexing and safer record-member recovery.

  • Validate scaled pointer-index strides against the recovered pointee size before rendering `p[i]`.
  • Use one pointee-size calculation for constant offsets and scaled variable indexes.
  • Resolve user-defined scalar and enum typedef sizes when rendering pointer offsets.
  • Recognize C character widths for `char8_t`, `char16_t`, and `char32_t`.
  • Recognize `_Bool` and `bool` pointee widths.
  • Recognize Windows byte, word, integer, HRESULT, and pointer-sized aliases.
  • Recognize common POSIX process and socket scalar aliases.
  • Recover pointer types through typed calls, function-pointer aliases, conditional expressions, and pointer arithmetic.
  • Normalize repeated `const`, `volatile`, and `restrict` qualifiers across pointer, callback, and nested field types.
  • Follow qualified nested record aliases and qualified array element types during member-path recovery.
  • Keep ambiguous multi-member union accesses explicit instead of selecting an arbitrary field.
  • Keep overlapping bitfield storage accesses explicit when byte offsets cannot identify one field.
  • Preserve the current type-layout model's widths for 64-bit `long`, `size_t`, and related scalar aliases.
  • Weighted parity remains 41.8%; the 50% target remains unmet.
  • GitHub Actions builds the release artifact; no local build or installation was performed.
