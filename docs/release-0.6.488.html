Lens release

0.6.488 — Fourier

Native child debugging, expanded behavior triage, and cross-architecture analysis fixes.

  • Native local-child launch supports safely parsed arguments, environment assignment/removal, and a configurable working directory.
  • On macOS and Linux, traced launches can stop at program entry, single-step, and forward target fault signals when resumed.
  • Child stdout and stderr are captured into a bounded 64 KiB output pane, with copy and clear controls.
  • A bounded process timeline records launch, stop, exit-code, and signal-termination events, and supports copy and clear.
  • Exited children can be restarted with the same configuration; the process ID is shown and can be copied.
  • Static and runtime-correlatable behavior triage now covers file deletion/truncation, configuration deletion, file downloads, and process signaling/termination.
  • Decompiler enum identity survives unary plus, minus, and complement expressions.
  • Motorola 68000 TAS flags now reflect the signed byte tested by the instruction.
  • Parity estimate: 41.0% weighted capability coverage; about 42–47% practical workflow capability. The 50% target remains unmet.
  • GitHub Actions builds the release artifact; no local build or installation was performed.
