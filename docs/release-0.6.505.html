Lens release

0.6.505 — Fourier

Lower memory use for large zero-filled program sections.

  • ELF NOBITS and load-segment virtual tails no longer allocate padded zero buffers.
  • PE virtual section tails are represented by their mapped size instead of copied zero bytes.
  • Mach-O zero-fill sections and padded section tails remain virtual rather than eagerly allocated.
  • ELF, PE, and Mach-O keep their full mapped address ranges for navigation and decoding.
  • Virtual addresses beyond file-backed data now read as zero bytes through a shared bounded chunk.
  • Zero-filled reads work beyond the former 64 MiB allocation cap.
  • Hex displays virtual zero-fill as 00.
  • Byte and string scans continue to inspect file-backed data only.
  • Large BSS sections no longer reserve one allocation per section.
  • Raw file-backed segment contents and their source offsets remain available.
  • Weighted IDA Pro parity remains 41.8%; the 50% target remains unmet.

GitHub Actions builds the release artifact; no local build or installation was performed.
