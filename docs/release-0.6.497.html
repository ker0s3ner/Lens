Lens release

0.6.497 — Fourier

Categorized debugger runtime events with code navigation and structured handoff.

  • Classify debugger stops into faults, memory-watch events, breakpoints, signals, process exits, and other stops.
  • Mark fatal hardware and memory signals as high severity, watchpoints and other signals as medium, and ordinary debugger stops as informational.
  • Attach stopped program counters to events and navigate to mapped addresses directly from the event list.
  • Resolve stopped addresses to recovered functions and matching static behavior-triage signals.
  • Summarize high- and medium-severity events, and use Triage only to hide informational stops.
  • Copy event summaries as tab-separated records or standalone JSON.
  • Include structured runtime events and severity totals in JSON trace exports while retaining the existing string event field.
  • Keep the weighted IDA Pro estimate at 41.8%; the 50% target remains in progress.
  • GitHub Actions builds the release artifact; no local build or installation was performed.
