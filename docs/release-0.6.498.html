Lens release

0.6.498 — Fourier

Opt-in debugger watchpoints for statically flagged behavior APIs.

  • Find direct calls and indirect import-slot calls to imported APIs linked to static behavior-triage signals.
  • Rank candidate sites by the strongest matched signal and then by address, with a 64-site session limit.
  • Set temporary breakpoints on executable call instructions only; saved user breakpoints and their conditions are preserved.
  • Apply automatic watchpoints only when launching the loaded program locally. Remote and PID-attached sessions skip local-image addresses and explain why.
  • Use software breakpoints for behavior watch; if hardware-breakpoint mode is selected, show the candidate count and explain that automatic watchpoints were not armed.
  • Show the number of behavior call sites available before launch and log how many are armed.
  • Label a hit as a behavior call-site stop before the API executes, and show its caller, imported API, matching static heuristic signals, and effective severity.
  • Keep flagged API hits visible under Triage only, color them by severity, and navigate back to the call site.
  • Copy enriched runtime events as TSV or JSON and include API/caller details, effective severity totals, and an explicit stopped_before_api_call state in trace JSON.
  • The debugger stops immediately before a watched call, which may change execution timing. Signals are heuristic clues for defensive review, not proof of malicious behavior.
  • Keep the weighted IDA Pro estimate at 41.8%; the 50% target remains in progress.
  • GitHub Actions builds the release artifact; no local build or installation was performed.
