Lens release

0.6.486 — Fourier

Prototype-seeded pointer recovery and a behavior-aware runtime call timeline.

  • DWARF fixed member layouts now accept unsigned and nonnegative signed constant-plus expressions.
  • Dynamic and unsupported member-offset expressions remain excluded from recovered layouts.
  • Decompiler types from known function prototypes now seed local pointer recovery.
  • Pointee types survive integer-offset dereferences, including variable indexes and conditional pointers.
  • Debugger traces identify observed direct and indirect call transitions into known functions.
  • Observed calls are matched to explainable static behavior signals and highlighted in the debugger.
  • Call timelines can be copied, navigated, and exported with step, caller, callee, addresses, and signals.
  • IDA Pro parity estimate: 39.5% weighted capability coverage; the 50% target remains in progress.
  • GitHub Actions builds the release artifact; no local build or installation was performed.
