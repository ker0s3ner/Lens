0.6.510 — Fourier

Mach-O embedded-data ranges are now validated and indexed for repeated code/data checks.

  • Sort LC_DATA_IN_CODE ranges once after parsing.
  • Merge overlapping and adjacent ranges into compact intervals.
  • Skip empty or reversed intervals.
  • Clip embedded-data ranges to the file-backed portion of their containing segment.
  • Check virtual-address addition before accepting each interval.
  • Use binary search for repeated executable and function-prologue membership checks.
  • Keep embedded literal pools excluded from guessed function starts.
  • Keep non-Mach-O analysis on the empty-range path.
  • Weighted IDA Pro parity remains 41.8%; the 50% target remains unmet.

GitHub Actions builds the release artifact; no local build or installation was performed.
