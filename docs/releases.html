Release archive

What's new in Lens.

Lens uses mathematical codenames. Versions follow x.y.z: major theme releases, monthly minor feature releases, and patch releases for fixes and quality of life.

0.6.4 — Fourier

November 2026 · GitHub release

  • x86 div and idiv now preserve the implicit wide dividend, quotient, and remainder in pseudocode.
  • The Fourier patch line continues to improve native-code navigation and analysis coverage.

0.6.3 — Fourier

November 2026 · GitHub release

  • Common Swift $s symbols now retain readable module and declaration components.
  • C enum parsing accepts named-member expressions and common C integer constants.
  • ELF GNU IFUNC symbols and PE TLS callbacks now seed function discovery.

0.6.2 — Fourier

November 2026 · GitHub release

  • ARM64 bitfield, extract, rotate, and conditional-integer idioms now render as readable pseudocode.
  • Recovered switch-case destinations now appear as call-graph edges.
  • Scripts can inspect comments, bookmarks, and persisted data definitions.

0.6.1 — Fourier

November 2026 · GitHub release

  • Rhai scripts can retrieve typed C-like pseudocode with decompile(addr).
  • Incoming and outgoing xrefs preserve relationship kinds in scripts.
  • The Rhai API exposes script_api_version() and includes a versioned example plugin.
  • Packed C declarations now compute byte-aligned field layouts.

0.6.0 — Fourier

November 2026 · GitHub release

  • Itanium C++ vtable metadata headers are recognized before method-pointer runs are validated.
  • ARM and Thumb PC-indexed inline switch tables are recovered with bounded case counts.
  • ARM64 NEON registers and common floating-point arithmetic are preserved in pseudocode.
  • Switch-case cross-references are distinct from ordinary direct jumps in listings and exports.
  • Release notes are available inside Lens and in this public archive.
