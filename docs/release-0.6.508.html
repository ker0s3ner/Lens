0.6.508 — Fourier

Older DWARF bitfield formats now produce bounded, endian-aware type layouts.

  • Import legacy DWARF 2, 3, and 4 bitfields that use DW_AT_bit_offset.
  • Keep DWARF 5 DW_AT_data_bit_offset handling intact.
  • Convert legacy bit positions for little-endian targets; preserve target positions for big-endian layouts.
  • Place legacy bitfields relative to their storage member, including positions inside multi-byte storage units.
  • Reject bit positions outside their declared storage unit.
  • Reject bitfield and ordinary member extents that exceed their containing record.
  • Check member-end arithmetic for overflow before accepting a layout.
  • Skip valid unnamed zero-width bitfield separators without discarding the record.
  • Avoid wrapping unsigned DWARF enum values that do not fit the signed type database.
  • Weighted IDA Pro parity remains 41.8%; the 50% target remains unmet.

GitHub Actions builds the release artifact; no local build or installation was performed.
