0.6.502 — Fourier

Optional short string previews for behavior API arguments.

  • Enable Preview narrow C-string arguments under behavior API watching in the debugger.
  • Use recovered prototypes to select narrow character pointers, including common Windows narrow-string aliases.
  • Read at most four string arguments per event, capped at 96 bytes each, and stop at the first NUL.
  • Keep raw register values and show escaped previews beside known parameter names and types.
  • Carry previews into runtime-event TSV and JSON handoffs and dynamic-trace JSON.
  • Keep unreadable pointers as raw values without previews; wide-character pointers are not interpreted.

String inspection is off by default and only runs after you enable it. Reads happen while stopped before the watched API call. The weighted IDA Pro parity estimate remains 41.8%.
