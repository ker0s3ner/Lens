Lens release

0.6.503 — Fourier

More useful dynamic behavior triage.

  • Show watched API events under process, filesystem, registry, memory, network, and anti-debugging categories when their names match known APIs.
  • Filter the runtime event list by category, independently of the triage-only severity filter.
  • Include category labels in event TSV and JSON and per-category counts in dynamic-trace JSON.
  • Preview common Windows UTF-16 parameters such as LPCWSTR, LPWSTR, PCWSTR, and PWSTR when the opt-in is enabled.
  • Bound Windows UTF-16 reads to 192 bytes (96 code units), decode surrogate pairs lossily, and stop at the first null code unit.
  • Retain the four-argument event limit, the 96-byte narrow-string limit, raw pointer values, and unreadable-pointer behavior.
  • Categories come from imported API names and static heuristic matches. They are triage labels, not operating-system telemetry or proof an operation completed.

The weighted IDA Pro parity estimate remains 41.8%; the 50% target remains unmet. The build and release artifact were produced by GitHub Actions.
