0.6.509 — Fourier

Large binary snapshots share their segment storage until an edit needs a private copy.

  • Share segment byte buffers across cloned binary-analysis snapshots.
  • Debugger, database, scripting, and report snapshots reuse the same underlying segment buffers.
  • Patch writes detach only the edited segment, leaving earlier snapshots unchanged.
  • Reject oversized zero-fill writes before copy-on-write allocation.
  • Keep virtual zero-fill represented by logical size across snapshots.
  • Keep segment metadata and file-offset save behavior intact.
  • No memory reduction percentage is claimed until a snapshot-specific workload is measured.
  • Weighted IDA Pro parity remains 41.8%; the 50% target remains unmet.

GitHub Actions builds the release artifact; no local build or installation was performed.
